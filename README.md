# Password Strength Checker

A desktop app that checks whether a password is strong enough and explains how to improve it.

## Tools
Python, Tkinter (GUI)

## How it works
- User enters a password into a GUI text field (masked with *)
- Clicking "Check Strength" evaluates the password and shows a rating (Very weak to Very strong)
- Gives specific feedback, e.g. "try mixing letters, numbers, and symbols"

## What I learned
Building a simple GUI with Tkinter, and translating password security rules (length, character variety) into logic a non-technical user can understand from plain feedback.

## Possible improvements
Add a check against common/leaked password lists, show a strength meter bar.
